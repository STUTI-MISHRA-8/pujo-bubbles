YOUR DURGA PUJA LOVE-LETTER WEBSITE

IMPORTANT: Please EXTRACT the ZIP first. Do not preview/open index.html from inside the ZIP preview.

WINDOWS:
1. Download this ZIP.
2. Right-click it > Extract All... > Extract.
3. Open the extracted folder.
4. Double-click index.html.

Keep index.html, style.css, script.js, and the assets folder together in the same folder. If you move index.html by itself, the styling and photos/videos will break.

If it still appears unstyled:
- Make sure you opened index.html from the extracted folder, not the ZIP preview.
- Make sure style.css and script.js are beside index.html, and assets is beside them.
- Try Chrome or Edge.

To publish free:
1. Open https://app.netlify.com/drop
2. Sign in or create a free account.
3. Drag the ENTIRE extracted maha-ashtami-love-letter folder onto the drop area (or zip the contents/folder and upload as the interface requests).
4. Netlify will give you a public website link to share.

The Google Fonts import uses internet access; if offline, the site will use fallback fonts. All photos/videos are included locally.
